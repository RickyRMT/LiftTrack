# LiftTrack

LiftTrack is a workout tracking application built to log workouts, calculate PRs, track fitness progress, and strengthen my software engineering skills through real-world development.

## Introduction

This project marks the beginning of my post-graduation software development journey.

After completing my degree, I wanted to focus on building personal projects that help reinforce computer science concepts, strengthen my foundations, and progressively challenge me with larger and more advanced systems over time.

Rather than immediately jumping into large-scale applications, my goal is to begin with small features, understand every part of the development process, and gradually expand this project into something more complex.

---

## Project Background

Recently I have become heavily invested in fitness and the gym, so I wanted my first major project to be centered around an interest I genuinely enjoy.

LiftTrack combines two things I care about:

- Fitness
- Software engineering

This project will begin with smaller features and evolve over time into a larger full-stack application.

Planned features include:

- PR calculator
- Workout logging
- Push/Pull/Leg templates
- Workout history
- Personal records tracking
- Progress analytics
- Bodyweight tracking
- Authentication
- Cloud storage
